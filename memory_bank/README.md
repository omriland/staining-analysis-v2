# Memory Bank

This folder holds concise notes about the repository's analysis scripts: purpose, pipelines, key parameters, inputs/outputs, and caveats.

## Start-of-chat rule
- At the beginning of every new chat about this project:
  1) Read all files under `memory_bank/`.
  2) Compare against current scripts. If parameters/I-O/behavior changed, update the relevant note(s) immediately.
  3) Use these notes to keep terminology and conventions consistent when proposing changes or creating new analyses.

## Files
- `repo_overview.md`: Inventory of scripts with roles and I/O
- `dependencies.md`: Libraries and external requirements
- Script briefs: one file per main script with purpose, pipeline, parameters, and outputs

Keep entries short and operational.
