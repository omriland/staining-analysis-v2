---
title: Start-of-Chat — Read and Update Memory Bank
type: rule
version: 1
---

At the beginning of every new chat session for this project:

1) Read all files under `memory_bank/` (README, overview, dependencies, and script briefs).
2) Compare notes with the current codebase. If parameters, I/O, or behavior changed, update the relevant memory files immediately.
3) Use the memory notes to keep naming, units, and conventions consistent when proposing changes or creating new analyses.
